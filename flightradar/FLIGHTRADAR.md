# Flightradar24 Setup

Setup date: 2026-06-05

## Summary

The Raspberry Pi is configured as a Flightradar24 1090 MHz ADS-B feeder.

Use Tailscale for access (see [SETUP.md](../SETUP.md)):

```bash
ssh pi
```

FR24 feeder UI address over Tailscale (HTTP access was not retested on 2026-10-02):

```text
http://100.75.237.100:8754
```

Radar ID:

```text
T-EGLL421
```

The FR24 sharing key is intentionally not documented here.

## Hardware

Connected hardware:

- Nooelec RTL-SDR v5 SDR, NESDR SMArt HF/VHF/UHF, RTL2832U and R820T2/R860 based.
- Bingfu dual-band 978 MHz / 1090 MHz 7 dBi magnetic base antenna.

The SDR is detected by Ubuntu as:

```text
Bus 004 Device 002: ID 0bda:2838 Realtek Semiconductor Corp. RTL2838 DVB-T
```

## SDR / Decoder Fix

On Ubuntu 24.04, FR24's helper attempted to install the old package `librtlsdr0`, which is not available. The Noble-compatible packages were installed directly:

```bash
sudo apt-get install -y librtlsdr2 libusb-1.0-0 rtl-sdr dump1090-mutability lighttpd wget
```

`dump1090-mutability` was linked for FR24:

```bash
sudo ln -fs /usr/bin/dump1090-mutability /usr/lib/fr24/dump1090
```

The standalone `dump1090-mutability` service was disabled so `fr24feed` owns the decoder process:

```bash
sudo systemctl disable --now dump1090-mutability
```

The RTL-SDR DVB kernel drivers were blacklisted so the dongle is available to dump1090 instead of being claimed as a TV receiver:

```text
/etc/modprobe.d/rtl-sdr-blacklist.conf
```

Contents:

```text
blacklist dvb_usb_rtl28xxu
blacklist rtl2832
blacklist rtl2832_sdr
blacklist r820t
blacklist e4000
```

## Startup Behavior

`fr24feed` is enabled with systemd and was verified after reboot.

Startup checks:

```bash
systemctl is-enabled fr24feed
systemctl is-active fr24feed
fr24feed-status
```

Expected service state:

```text
enabled
active
```

Verified post-reboot status:

```text
FR24 Feeder/Decoder Process: running
FR24 Link: connected [UDP]
FR24 Radar: T-EGLL421
FR24 Tracked AC: 12
Receiver: connected
```

Runtime processes should include:

```text
/usr/bin/fr24feed
/usr/bin/dump1090-mutability --raw --mlat --write-json /run/dump1090-mutability/
```

## Useful Commands

Check SDR:

```bash
lsusb
```

Check FR24 status:

```bash
fr24feed-status
systemctl status fr24feed
```

Check the local monitor API from the Pi:

```bash
curl http://127.0.0.1:8754/monitor.json
```

Check logs:

```bash
journalctl -u fr24feed --no-pager -n 120
```

Restart the feeder:

```bash
sudo systemctl restart fr24feed
```

Reboot-test startup:

```bash
sudo reboot
```

Then reconnect with:

```bash
ssh pi
fr24feed-status
```
